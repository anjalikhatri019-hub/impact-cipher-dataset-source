# Dataset Description

## Overview

Impact Cipher is an original synthetic corpus of 2,400 isolated two-dimensional systems containing ten hard discs. Every disc is assigned a hidden positive mass, a visible radius, and an identity that remains fixed across four calibration trials and one counterfactual query. Pairwise contacts and square-wall impacts use unit restitution: kinetic energy and momentum are preserved by each disc-disc impulse, while walls reflect the normal velocity component.

The raw data contain no external measurements, copyrighted media, personal information, pretrained-model output, or third-party dataset. Numerical records are generated by the included Python simulator. Code and documentation are AI-assisted and should not be represented as unaided human work.

## Intended use

This dataset was created specifically for the **Impact Cipher: Counterfactual Elastic Collision Reconstruction** machine-learning challenge. A solver receives four noisy, incomplete calibration trajectories from one hidden ten-disc mass system, together with disc radii and the exact initial state of a new query experiment. The intended task is to infer the latent mass relationships and predict 45 cumulative pairwise collision impulses plus 20 terminal velocity components for the query.

The data support research and benchmarking in system identification, physics-informed learning, missing-observation reconstruction, counterfactual simulation, structured regression, and uncertainty-aware dynamical prediction. They are educational synthetic data. They are not intended for physical equipment design, collision-safety certification, forensic reconstruction, autonomous-control validation, or any decision involving people or real machinery.

## Files

- `impact_cipher_raw.parquet` — 2,400 complete raw systems.
- `generation_metadata.json` — version, dimensions, counts, hashes, and a one-way commitment to the organizer-held release seed.
- `generate_dataset.py` — original deterministic simulator; requires an explicit integer seed.
- `LICENSE.txt` — CC0 1.0 dedication for rights held by the creator.

## Raw columns

| Column | Type | Meaning |
|---|---|---|
| `sample_id` | string | Opaque raw identifier. |
| `split` | string | Organizer-only `train` or `test`. |
| `family_id` | int | Organizer-only mass-profile family, 0–29. |
| `validation_fold` | int | Organizer-only/public-train fold marker. |
| `mass_bytes` | binary | Organizer-only hidden float32 masses for reproducibility audits. |
| `radii_bytes` | binary | Little-endian float32 `[10]`. |
| `calibration_initial_bytes` | binary | Little-endian float32 `[4,10,4]` initial `(x,y,vx,vy)`. |
| `calibration_state_bytes` | binary | Little-endian float32 `[4,160,10,4]` noisy observed states. |
| `calibration_valid_bytes` | binary | uint8 `[4,160,10]`; validity is per disc state. |
| `query_initial_bytes` | binary | Little-endian float32 `[10,4]` counterfactual initial state. |
| `target_values` | string | 45 cumulative pair impulses then 20 terminal velocity components. |

Invalid calibration states are represented by four NaNs and a zero validity entry. Array order is C order. Pair order is lexicographic over `i < j`.

## Generation and split

There are 30 independently parameterized mass-profile families with 80 systems each. Families 0–19 form development training, 20–24 form public validation, and entire families 25–29 form the private test. Positions, velocities, radii, noise, missing blocks, object permutation, and counterfactual query are resampled per system. The public preparation removes `split`, `family_id`, `mass_bytes`, and all raw IDs; it independently remaps and shuffles each split.

The simulator uses sequential resolution of detected contacts at two fixed substeps per recorded interval. Each resolved pair collision applies the analytic frictionless unit-restitution hard-disc impulse. This is a deterministic discrete collision benchmark, not a claim of continuous-time molecular-dynamics accuracy or simultaneous multi-contact resolution.

## Known limitations

- The systems are synthetic two-dimensional unit-square arenas, not measurements of real collisions.
- Bodies are perfectly rigid circles with no rotation, surface friction, deformation, adhesion, drag, gravity, thermal effects, or material-dependent restitution.
- Disc-disc and wall impacts use unit restitution. Energy losses found in real materials are intentionally absent.
- Contact detection is discrete. The simulator advances each recorded interval using two fixed substeps, corrects overlap geometrically, and resolves detected pairs sequentially in lexicographic order. Near-simultaneous or multi-body contacts can therefore depend on the frozen resolution order and differ from an event-driven continuous-time solver.
- Momentum and kinetic energy are preserved by each analytic pair impulse up to floating-point precision, but geometric overlap correction is a positional numerical operation rather than a physical contact-duration model.
- Calibration noise is synthetic additive noise. Missing observations arise from a limited combination of independent dropout and contiguous blocks; they do not represent every sensor failure process.
- Disc identities, radii, calibration initial states, and query initial states are assumed known exactly. Real tracking systems can contain identity switches and calibration uncertainty not modeled here.
- Hidden masses come from 30 designed mass-profile families. Although complete families are held out for validation and testing, this family collection cannot represent the full space of possible mass distributions.
- Inputs are stored as float32. The release deliberately quantizes masses, radii, and initial states before simulation so published values define the benchmark, but float32 remains less precise than many scientific simulators.
- The 400-system private test estimates performance only for this generator and split. It does not establish real-world generalization, safety, or scientific validity outside the benchmark.
- Public generator code does not include the organizer seed. Publishing that seed would allow exact private-label replay, so authorized reproduction of the original release requires the organizer-held seed.
- Results may be sensitive to small mass-estimation errors because later collision order is chaotic. A low score does not by itself identify which inferred physical parameter was wrong.
